尚未設定 Supabase

請先在 assets/js/supabase-config.js 填入新專案的 Project URL 與 anon key，並套用 supabase/migrations 內的 SQL。詳見交接文件。

請以管理員 Google 帳號登入

一般帳號登入後僅為訪客，沒有任何編輯權限。

若無痕可以登入、一般視窗卻卡住：多半是本機舊的 auth token／PKCE 殘渣，請按上方按鈕。

你已登入，但不是管理員

你的帳號不在管理員白名單，只有訪客權限。若這是誤判，請聯絡站長把你的信箱加入白名單。

快速匯入文章

從 HackMD／Markdown／Threads／FB／IG 複製文字或連結貼下方 → 預覽 → 存成草稿或直接發佈。純本地解析，不會送到第三方。

  1. 貼上全文（可含 # 標題、YAML frontmatter、分類：短思）
  2. 按「預覽解析」檢查標題／摘要／篇幅
  3. 確認後「填入表單」再存檔，或直接「存成草稿」
