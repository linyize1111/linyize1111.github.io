# 遊戲評鑑評分規則

ACG Portal 站長評鑑採分項制（v1.4.0+）。

## 分項（6 項）

| 內部 key | 繁中標籤 | 必填 | 說明 |
|----------|----------|------|------|
| `story` | 劇情 | 是 | 故事、節奏、角色塑造 |
| `art` | 美術 | 是 | 立繪、CG、整體視覺完成度 |
| `voice` | 配音 | 否（可 N/A） | 無語音作品可標「不適用」 |
| `gameplay` | 系統 | 是 | 操作、系統深度、可玩性 |
| `presentation` | 表現力 | 是 | 氛圍、主題呈現與整體完成感 |
| `animation` | 演出 | 否（可 N/A） | 動圖／演出密度與品質；純靜態可 N/A |

## 分數範圍

- 每項：**整數 1–10**（10 最高）
- 選填項可為 `null`（UI 顯示「不適用」）

## 總分公式

```
總分 = round( 所有非 null 分項的算術平均 , 1 )
```

等權平均，略過 N/A。例：六項中兩項 N/A → 以其餘四項平均。

`games.rating` 存 `round(總分)`（1–10），供排序／舊欄位相容。

## 總評等級

| 等級 | 條件 | 標籤 |
|------|------|------|
| S | 總分 ≥ 9.0 | 神作 |
| A | 總分 ≥ 8.0 | 佳作 |
| B | 總分 ≥ 6.5 | 良作 |
| C | 總分 ≥ 5.0 | 普通 |
| D | 總分 < 5.0 | 雷 |

## 舊資料遷移

舊版單一評分 `-5～+5`：

- 對應分項分數 = `clamp(rating + 5, 1, 10)`
- 配音／演出設為 N/A
- 其餘四項填入對應分數

## 儲存欄位

- `scores` (jsonb)：分項
- `score_total` (numeric)：總分一位小數
- `grade` (text)：S/A/B/C/D
- `rating` (smallint)：總分四捨五入整數 1–10
