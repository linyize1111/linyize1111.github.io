# 文章匯入收件匣

把要重上的文章 **以 `.md` 檔** 放進對應子資料夾，檔名就是預設標題。

```
import-inbox/
├── literature/     ← 文學：認真寫的隨筆／心得／創作／長文
└── notes/          ← 雜記：隨手寫的隨想／日記／短感想
```

## 兩個分區怎麼分

| 資料夾 | 站上名稱 | 放什麼 |
|--------|----------|--------|
| `literature/` | **文學** | 較完整、較用心的文章 |
| `notes/` | **雜記** | 碎念、日記、隨便發的短文 |

## 檔名規則

| 檔名範例 | 標題 |
|----------|------|
| `該死的咖啡因.md` | 該死的咖啡因 |
| `2024-09-13_生活札記-中山大學入學.md` | 生活札記：中山大學入學 |

- 建議用 **中文檔名** 當標題。
- 日期可選加在檔名開頭 `YYYY-MM-DD_`。

## 可選 frontmatter

```markdown
---
title: 自訂標題
category: 日記
tags: 生活
status: draft
published: 2024-09-13
summary: 一句話摘要
---

正文…
```

**category 建議**

- 雜記（`notes/`）：`隨想` `日記` `感想`
- 文學（`literature/`）：`隨筆` `心得` `創作` `長文`

預設匯入為 **草稿**；貼完跟我說，我跑匯入並幫你整理。

詳見站上後台與 `docs/MAIN-SITE-IMPORT-TODAY.md`。
