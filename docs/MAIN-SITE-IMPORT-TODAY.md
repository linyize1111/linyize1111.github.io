## 三步流程（煩惱整理版）

1. **貼上** — 把 Threads／FB／備忘錄／HackMD 的文字複製進後台大框  
2. **存** — 按「存成草稿」  
3. **不用想分類** — 系統自動當「隨想」或「長文」；標籤預設空白

之後有空再改標題、點一下改分類、或把狀態改成 `published` 發佈。站上會自動整理好看：隨想用輕量卡片，長文維持原本卡片。

## 抱怨／碎念怎麼辦？

- 標籤：預設空白。想標再點「抱怨／想法／摘錄」
- 列表：[`literature.html`](https://linyize1111.github.io/literature.html) 選「只看隨想」，或開 [`?cat=隨想`](https://linyize1111.github.io/literature.html?cat=%E9%9A%A8%E6%83%B3)

## 後台怎麼用

1. 打開 `admin.html` → Google 登入管理員  
2. **快速匯入 · 零決策**  
   - 貼上內容  
   - 按 **存成草稿**（主按鈕）  
   - 「先預覽／填入表單」可跳過；分區與篇幅藏在「進階選項」  
3. 發佈：文章列表 → 編輯 → 狀態改 `published` → 儲存  

### 分類（系統自動，可一鍵改）

| 情況 | 自動分類 |
|------|----------|
| 短內容、抱怨、碎念（約 ≤450 字） | **隨想**（舊名「短思」已統一） |
| 很長（約 ≥2200 字） | **長文**（筆記區則偏「人文」） |
| 中篇 | 文學 → 隨筆；筆記 → 人文 |

表單裡「進階整理」可一鍵改成：隨想／長文／隨筆／心得／創作。**不必選也能存。**

### 標籤（可選）

預設空白，不強迫。需要時點建議：抱怨、想法、摘錄。

## 各來源要複製什麼

### HackMD

下載 Markdown 或全選複製 → 貼上 → 存成草稿。長文會自動標「長文」。

### Threads／Facebook／備忘錄

複製正文（不要只貼分享連結）→ 存。多半會進「隨想」。

### Instagram

圖說能複製就貼；圖內文字請自行打字或 OCR。封面建議上傳，少用社群 CDN。

### 可選 frontmatter（完全不需要）

```markdown
---
title: 今天的隨想
category: 隨想
tags: 抱怨
---

內文…
```

## 疑難排解

| 狀況 | 作法 |
|------|------|
| 只貼了網址 | 改貼全文 |
| slug 已存在 | 換 slug 或編輯舊文 |
| 標題怪 | 存完後編輯改標題，或讓系統用日期隨想 |
| 想改成長文 | 編輯 → 進階整理 → 點「長文」 |
| 圖片破圖 | 改上傳到站內 Storage |
| 登入卡住 | 「清除登入資料後重登」 |
