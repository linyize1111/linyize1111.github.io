## 後台怎麼用（新介面）

1. 打開 `admin.html` → Google 登入管理員。
2. 上方 **快速匯入文章** 卡片：
   - **預設分區**：文學隨筆 / 學科筆記
   - **篇幅提示**：自動／短思／長文（會建議分類）
   - 大文字框貼上內容
3. 按 **① 預覽解析** → 看標題、摘要、篇幅徽章、內文預覽。
4. 二選一：
   - **② 填入表單**：進下方編輯區微調（封面、標籤、狀態）再按儲存
   - **直接存成草稿**：立刻寫入 DB（status=draft），之後再編輯發佈
5. 發佈：編輯該篇 → 狀態改 `published` → 儲存。文學站 `literature.html`、筆記站 `directory.html` 會自動列出。

### 分類建議

- **短思**：Threads／IG／FB 短感想（約 ≤450 字）
- **隨筆／心得／創作**：一般長度
- **長文**：HackMD／長篇讀書筆記（約 ≥2200 字）

## 各來源要複製什麼、貼哪裡

### HackMD

1. 開筆記 → 右上選單 → **Download** 選 Markdown，或編輯模式全選複製。
2. 建議開頭保留：

```markdown
---
title: 你的標題
category: 長文
tags: 閱讀, 札記
---

# 你的標題

第一段會當摘要…

其餘 Markdown 內文…
```

3. 貼到後台快速匯入框 → 預覽 → 存。

圖片：若是 `![](https://…)` 會自動當封面／附加圖；相對路徑圖請改成公開 URL 或到表單用「上傳」。

### Threads

1. 打開貼文 → 選取**正文文字**複製（不要只複製分享連結）。
2. 可順手刪掉 `Like` / `Reply` / 讚數等 UI 字；匯入器也會試著過濾。
3. 貼上後選篇幅 **短思** → 預覽。
4. 第一行若夠短會當標題；不滿意就填入表單後改標題。

### Facebook

1. 貼文「查看更多」展開 → 全選正文複製。
2. 貼上；圖片請另開大圖複製圖片網址貼到「主圖」，或本機下載後用上傳。
3. FB 外連圖網址常有時效，**建議上傳到站內 Storage** 較穩。

### Instagram

1. App／網頁通常不好一次複製長文；有「備註／圖說」就複製圖說。
2. 長文若只在圖片裡，請自行打字或 OCR 後貼上。
3. 封面用上傳，不要依賴 `cdninstagram.com` 熱鏈（易失效）。

### 純 Markdown／備忘錄

直接貼；可用：

```text
標題：今天的短思
分類：短思
tags: 日常

內文從這裡開始…
```

系統**沒有**也**不會假裝**已從下列帳號抓完全部貼文：

- Facebook（個人牆／粉專舊文）
- Instagram（圖說與限動文字）
- Threads（歷史短思）
- HackMD 上尚未下載的筆記
- 任何只存在手機備忘錄、未匯出的草稿

請依上面步驟，把還沒進站的貼文一篇篇貼進後台。  
若某篇標題已在上方 15 篇清單裡，就不用重貼（避免 slug 衝突）；要更新請在文章列表按「編輯」。

## 疑難排解

| 狀況 | 作法 |
|------|------|
| 只貼了網址 | 無法抓遠端全文；請改貼內容 |
| slug 已存在 | 換 slug 或改編輯舊文 |
| 解析標題怪 | 預覽後「填入表單」手動改標題／摘要 |
| 圖片破圖 | 改上傳；少用社群 CDN 熱鏈 |
| 登入卡住 | 後台「清除登入資料後重登」 |
